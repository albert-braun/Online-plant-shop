# FOLIA

Minimalist plant shop for a Berlin atelier: catalogue, filters, cart drawer, and a contact form. Single-page storefront with serif headlines and cut-out plant photos. Frontend demo — checkout stays on the client.

**Live:** [albert-braun.github.io/Online-plant-shop](https://albert-braun.github.io/Online-plant-shop/)

## What it does

- **Catalogue** — 20 plants priced in euros
- **Search and filters** — light needs and category
- **Cart** — sliding bag, quantities, toast feedback
- **Contact** — client-side form for the atelier

**Stack:** React 19 · Vite · Tailwind CSS · Redux Toolkit

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
